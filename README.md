# Contexto

## Sobre o projeto

O Contexto é um projeto de briefing diário de notícias desenvolvido para coletar, organizar e apresentar informações relevantes de forma automatizada.

## Objetivo

Construir uma aplicação capaz de buscar notícias em diferentes fontes, processar essas informações e gerar um briefing diário organizado para o usuário.

## Status do projeto

Em desenvolvimento.
